# .well-known Directory

This directory contains well-known URIs as defined by [RFC 5785](https://tools.ietf.org/html/rfc5785).

Well-known URIs are standardized paths that applications and services use to discover configuration, security policies, and other metadata about this domain.

## Common Files

- `security.txt` - Security policies and vulnerability disclosure information
- `robots.txt` - Search engine crawler directives
- `sitemap.xml` - XML sitemap for search engines
- `assetlinks.json` - Digital asset links for Android apps
- `apple-app-site-association` - App associations for iOS

## Usage

Add relevant well-known files to this directory based on your service requirements.
